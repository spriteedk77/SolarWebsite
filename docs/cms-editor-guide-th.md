# คู่มือจัดการเนื้อหา NP88 Solar

ใช้หลังผู้ดูแลเชื่อมบัญชี Sanity จริง ตอนนี้ GitHub Pages อ่าน snapshot ใน repo จึงยังไม่เปลี่ยนตาม Studio

## เพิ่มผลงานติดตั้ง

1. เปิด Studio เลือก **ผลงานติดตั้ง → สร้างเอกสาร**
2. กรอกชื่อ จังหวัด ประเภทลูกค้า คำอธิบายย่อและเนื้อหา ใส่ชื่อลูกค้าเมื่อได้รับอนุญาต
3. ใส่ชื่อ URL เป็นอังกฤษตัวเล็ก เช่น `clinic-chiang-mai` หลังเผยแพร่ควรคง URL เดิม หากต้องเปลี่ยนให้ผู้ดูแลทำ redirect ก่อน
4. กรอก **ระบบ Solar**, **อุปกรณ์**, **ผลประหยัดโดยประมาณ** ตามเอกสารจริง ไม่เดารุ่น/กำลังไฟ/การรับประกัน
5. ใน **รูปภาพ** อัปโหลดหน้าปกและภาพเพิ่มเติม พร้อมคำอธิบายสิ่งที่เห็น ห้ามอัปโหลดบิลค่าไฟหรือเอกสารส่วนตัว
6. ตรวจ **SEO** หรือเว้นว่างเพื่อใช้ชื่อและสรุป เลือก **แนะนำบนหน้าแรก** หากต้องการแสดงในผลงานเด่น
7. ยืนยันข้อมูลและสิทธิ์ภาพใน **สถานะเผยแพร่** แล้วกด **Publish** ระหว่างแก้ไขระบบบันทึก draft ซึ่งยังไม่เปลี่ยนหน้าเว็บ

## เขียนบทความ

เลือก **บทความความรู้** กรอกชื่อ สรุป หมวดหมู่ ผู้เขียนจริง และรูปหน้าปก ใช้แถบเครื่องมือสำหรับหัวข้อ ตัวหนา รายการ ลิงก์ รูป ข้อความอ้างอิงและตาราง ไม่ต้องเขียน Markdown/HTML

หัวข้อหลักตั้งแต่ 3 หัวข้อจะมีสารบัญ ตารางต้องมีจำนวนช่องแต่ละแถวเท่าหัวตาราง เลือกบทความที่เกี่ยวข้องได้ จากนั้นตรวจ SEO วันที่ และ Publish

## เปลี่ยนข้อมูลและโปรโมชั่น

- **ข้อมูลบริษัทและช่องทางติดต่อ**: โทร LINE ที่อยู่ พื้นที่บริการ Facebook และเวลาทำการที่ยืนยันแล้ว ใช้ร่วมกันทั่วเว็บ
- **หน้าแรกและข้อความหลัก**: หัวเรื่อง คำอธิบาย ข้อความเหนือหัวเรื่อง ข้อความปุ่มและท้ายเว็บ ปุ่มประเมิน/ผลงานใช้ปลายทางเดิม
- แผนที่ไม่จำเป็น หากไม่มี embed ที่ถูกต้อง หน้า Contact แสดงที่อยู่และช่องทางสอบถามเส้นทาง
- **โปรโมชั่น / แพ็กเกจ**: ใส่ราคา ขนาดระบบ อุปกรณ์ เงื่อนไขที่ยืนยันแล้ว วันเริ่ม/จบ และเปิดใช้งาน แพ็กเกจ inactive/หมดอายุไม่แสดง

หลัง Publish ตรวจเว็บไซต์จริงบนมือถือและคอมพิวเตอร์ อาจต้องรอ cache refresh ประมาณหนึ่งนาทีและโหลดซ้ำ หากไม่ขึ้นให้แจ้งผู้ดูแลพร้อม URL

ไม่ใช้จำนวน 600+ / 700+, ราคา หรือการรับประกันที่ยังไม่ยืนยัน เมื่อ validation เตือน ให้เติมข้อมูลจริงหรือคง draft ไว้ ไม่ใส่ข้อมูลสมมติเพื่อให้ผ่าน
