# Photo brief — ภาพที่ต้องการจาก NP88 Solar

เว็บไซต์นี้ออกแบบให้ใช้ **ภาพถ่ายงานติดตั้งจริง** เป็นภาษาภาพหลัก ไม่ใช่ภาพ
illustration หรือ stock photo ขณะนี้ทุกช่องภาพเป็นกราฟิกกลาง ๆ ในสีแบรนด์
(ไม่มีข้อความกำกับใด ๆ) เพื่อให้หน้าเว็บพร้อมใช้งานจริงระหว่างรอไฟล์ภาพ

## วิธีนำภาพจริงเข้าเว็บไซต์

1. วางไฟล์ไว้ที่ `public/images/projects/<slug>/` หรือ `public/images/sections/`
   ใช้นามสกุล `.jpg` หรือ `.webp` (**อย่าใช้ `.svg`** — ดูข้อ 4)
2. แก้ path และ `alt` ในไฟล์เนื้อหา (`src/content/th/projects.ts`,
   `src/content/th/articles.ts`, `src/content/th/products.ts`)
3. ลบ `placeholder: true` ออก (ตอนนี้ใช้เป็นข้อมูลภายในเท่านั้น ไม่มีผลต่อหน้าเว็บ)
4. **ภาพแชร์ลงโซเชียล:** ระบบจะเลือกภาพจริงให้อัตโนมัติทันทีที่ไฟล์เป็น
   `.jpg` / `.png` / `.webp` — ดู `resolveSocialImage()` ใน `src/lib/seo.ts`
   ระหว่างที่ยังเป็น `.svg` ระบบจะใช้ภาพ OG ที่สร้างเป็น PNG แทน
   เพราะ LINE / Facebook / Google ไม่รองรับ SVG
5. ภาพพื้นหลังของ hero แต่ละหน้าอยู่ในคอมโพเนนต์โดยตรง
   (`src/components/home/Hero.tsx`, `BusinessSection.tsx`, และ `image` prop ของ `PageHero`)

## ข้อกำหนดทางเทคนิค

| หัวข้อ | ค่าที่ต้องการ |
| --- | --- |
| ความละเอียดขั้นต่ำ | 2400 × 1350 px (16:9) สำหรับภาพเต็มความกว้าง |
| รูปแบบไฟล์ต้นฉบับ | JPEG คุณภาพสูง หรือ HEIC จากมือถือรุ่นใหม่ (ระบบแปลงเป็น WebP/AVIF ให้เอง) |
| แนวภาพ | แนวนอนเป็นหลัก มีแนวตั้งบ้างสำหรับอุปกรณ์ |
| สิ่งที่ต้องเลี่ยง | ใส่โลโก้หรือข้อความทับบนภาพ เพราะเว็บไซต์จัดวางข้อความเอง |
| การขออนุญาต | ต้องได้รับอนุญาตจากเจ้าของสถานที่ก่อนเผยแพร่ทุกภาพ |

## รายการภาพที่ต้องการ (เรียงตามความสำคัญ)

### ลำดับ 1 — จำเป็นต่อความน่าเชื่อถือของหน้าแรก

1. **Hero หน้าแรก** — หลังคาที่ติดตั้งเสร็จแล้ว ถ่ายมุมกว้างหรือมุมสูง
   ให้เห็นแถวแผงเป็นระเบียบ ควรมีท้องฟ้าเปิดในเฟรม (มีที่ว่างด้านซ้ายสำหรับข้อความ)
2. **Hero สำหรับธุรกิจ** — หลังคาโรงงานหรือคลังสินค้าขนาดใหญ่
3. **ทีมงานหน้างาน** — ช่างกำลังทำงานจริง สวมอุปกรณ์ความปลอดภัย
4. **งานออกแบบ/ตรวจสอบ** — วิศวกรกับแบบระบบ หรือหน้าจอ Monitoring

### ลำดับ 2 — หน้าโครงการ (ต้องการชุดละ 4–6 ภาพต่อโครงการ)

สำหรับแต่ละโครงการใน `src/content/th/projects.ts`:

- ภาพรวมหลังคาหลังติดตั้งเสร็จ
- รายละเอียดการจัดวางแถวแผงและช่องทางเดินบำรุงรักษา
- จุดติดตั้งอินเวอร์เตอร์ / ตู้ควบคุม
- แบตเตอรี่ (เฉพาะโครงการที่มี)
- Optimizer หรืออุปกรณ์พิเศษ (เฉพาะโครงการที่มี)
- หน้าจอแอปพลิเคชัน Monitoring (ถ้ามี)

โครงการที่รอภาพอยู่ตอนนี้:

### ลำดับ 3 — สินค้าและบทความ

- แผงโซลาร์แต่ละรุ่นที่ใช้จริง (JA Solar N-Type, Bifacial, AIKO STELLAR)
- อินเวอร์เตอร์ Deye, แบตเตอรี่ Dyness, ชุด SigenEnergy NEO
- Smart PV Optimizer ที่ติดตั้งอยู่หลังแผง
- ภาพประกอบบทความ: หลังคาบ้าน, หลังคาโรงงาน, การสำรวจหน้างาน

## เรื่องที่ต้องระวัง

- **อย่าใช้ภาพจากผู้ผลิตหรือจากอินเทอร์เน็ต** หากไม่มีสิทธิ์ใช้งาน
- หากภาพมีชื่อร้าน ป้าย หรือทะเบียนรถที่ระบุตัวลูกค้าได้
  ต้องได้รับอนุญาตหรือเบลอก่อนเผยแพร่
- ภาพที่มีคนต้องได้รับความยินยอมจากบุคคลในภาพ
