# รายการข้อมูลที่ต้องยืนยันก่อนเผยแพร่จริง

เว็บไซต์นี้สร้างขึ้นภายใต้กติกาเดียว: **ห้ามแต่งข้อมูลขึ้นเอง** ไม่ว่าจะเป็นชื่อลูกค้า
สถานที่ ราคา ใบรับรอง การรับประกัน ใบอนุญาต สถานะตัวแทนจำหน่าย จำนวนงานติดตั้ง
หรือตัวเลขการประหยัด สิ่งที่ยังไม่ได้รับการยืนยันถูกบันทึกไว้ทั้งหมดที่
[`src/lib/pending.ts`](../src/lib/pending.ts)

> **เปลี่ยนแปลงสำคัญ:** เดิมรายการเหล่านี้ถูกแสดงเป็นกล่องหมายเหตุบนหน้าเว็บ
> ซึ่งเหมาะกับช่วงตรวจสอบภายใน แต่ไม่เหมาะกับหน้าเว็บที่ลูกค้าเห็น
> ตอนนี้จึงใช้หลักว่า **ข้อมูลที่ยังไม่ยืนยัน = ไม่เผยแพร่** ไม่ใช่เผยแพร่พร้อมคำเตือน
> และเขียนเนื้อหาให้อ่านได้เป็นธรรมชาติโดยไม่ต้องมีตัวเลขนั้น

> รันเซิร์ฟเวอร์ในโหมดพัฒนาแล้วดูใน console จะเห็นจำนวนรายการที่ยังค้างอยู่

## C. เรื่องที่เว็บไซต์ **จงใจไม่ทำ**

สิ่งเหล่านี้ไม่ได้ลืม แต่ตั้งใจไม่ใส่ เพราะจะเป็นการกล่าวอ้างเกินจริง

- ไม่มีรีวิวลูกค้าหรือ `aggregateRating` ใน structured data (ห้ามสร้างรีวิวปลอม)
- ไม่ระบุสถานะ "ตัวแทนจำหน่ายอย่างเป็นทางการ" หรือ "พาร์ทเนอร์" ของยี่ห้อใด
- ไม่รับประกันตัวเลขการประหยัดค่าไฟ — ใช้คำว่า "ประมาณ" และมี disclaimer ทุกจุด
- ไม่อ้างอิงเงื่อนไขหรือขั้นตอนของการไฟฟ้าแบบเจาะจง — ใช้ถ้อยคำที่ชี้ให้ตรวจสอบเป็นรายกรณี
- ไม่มีสถิติอื่นนอกจากจำนวนไซต์งาน เพราะยังไม่มีข้อมูลที่ยืนยันได้

## D. เมื่อยืนยันข้อมูลแล้วต้องทำอะไร

1. แก้ค่าในไฟล์เนื้อหาที่เกี่ยวข้อง (`src/content/th/*`, `src/lib/site.ts`)
2. ลบรายการนั้นออกจาก `pendingRegister` ใน `src/lib/pending.ts`
3. เพิ่มเนื้อหาที่ยืนยันแล้วเข้าไปในหน้าที่เกี่ยวข้อง (ดูคอลัมน์ "จะใช้ที่")
4. รัน `npm run typecheck` และ `npm run build` เพื่อยืนยันว่าไม่มีอะไรพัง
